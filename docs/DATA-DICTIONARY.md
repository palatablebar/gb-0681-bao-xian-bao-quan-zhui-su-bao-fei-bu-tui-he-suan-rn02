# 保费补退定义

每份保单有且仅有一条issue基线。change按effective、责任、version选版；同生效日同版本矛盾拒绝。cancel必须引用同保单的change，取消整份变更，不按录入顺序覆盖。区间为[start,end)。年度保费按所在自然年365或366日拆分，跨年强制切段。先求每段精确保费，再最大余额法分配到分，使段合计等于保单总额。paid为已收金额，总应收减已收为补退额，正数补缴、负数退费。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

## 复效裁决

断缴凭证字段：case_id、policy_id、due_date（应缴日）、grace_end（宽限期末）、received_at（到账日）、accident_at（报案事故日）、period_end（保障期间末）、premium（欠缴保费）、claim_amount（报案赔款）、interest_charged（已收利息）。约束：应缴日<到账日≤宽限期末，事故日落在[应缴日,到账日)断缴窗口内，保障期间末>到账日；超出宽限期补缴返回GRACE。凭证登记后不可改写，同案异文返回409。

恢复基准二选一，结案前裁决。恢复期间为半开区间[恢复日,保障期间末)。按应缴日（due）：恢复日=应缴日，应补保费=欠缴保费全额，窗口内事故补付赔款，已收利息全额退还。按到账日（receipt）：恢复日=到账日，应补保费=欠缴保费×剩余天数/窗口总天数（四舍五入到分），窗口内事故不在保障期、赔款为0，利息不退。最终净额=应补保费−赔款−退还利息，正数客户应付、负数公司应付。金额Decimal到分，序列化为字符串。

案件状态机：待裁决→已裁决→已结案。结案必须已裁决；结案后裁决锁定；结案下载要求已结案。页面与结案CSV共用同一裁决视图。同一案件重复登记、同一基准重复裁决、重复结案均为幂等空转，不新增赔款或补费；裁决替换按版本条件更新，版本不符返回409且旧版保留。
